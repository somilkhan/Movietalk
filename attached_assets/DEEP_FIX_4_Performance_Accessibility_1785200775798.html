4.3 — ADD Keyboard Navigation (Global Shortcuts)

WHY: Power users expect keyboard shortcuts. Netflix, YouTube, and every major streaming app support: Space (play/pause), F (fullscreen), M (mute), Arrow keys (seek/volume), K (play/pause). Without these, your app feels amateur.
artifacts/allrated/src/hooks/useKeyboardShortcuts.ts (NEW)
import { useEffect } from "react";

interface Shortcuts {
  onPlayPause?: () => void;
  onFullscreen?: () => void;
  onMute?: () => void;
  onSeekForward?: () => void;
  onSeekBackward?: () => void;
  onVolumeUp?: () => void;
  onVolumeDown?: () => void;
  onNext?: () => void;
  onPrev?: () => void;
}

export function useKeyboardShortcuts(shortcuts: Shortcuts) {
  useEffect(() => {
    function handleKeyDown(e: KeyboardEvent) {
      // Ignore if user is typing in an input
      if (e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement) return;

      switch (e.key.toLowerCase()) {
        case " ":
        case "k":
          e.preventDefault();
          shortcuts.onPlayPause?.();
          break;
        case "f":
          e.preventDefault();
          shortcuts.onFullscreen?.();
          break;
        case "m":
          e.preventDefault();
          shortcuts.onMute?.();
          break;
        case "arrowright":
        case "l":
          e.preventDefault();
          shortcuts.onSeekForward?.();
          break;
        case "arrowleft":
        case "j":
          e.preventDefault();
          shortcuts.onSeekBackward?.();
          break;
        case "arrowup":
          e.preventDefault();
          shortcuts.onVolumeUp?.();
          break;
        case "arrowdown":
          e.preventDefault();
          shortcuts.onVolumeDown?.();
          break;
        case "n":
          e.preventDefault();
          shortcuts.onNext?.();
          break;
        case "p":
          e.preventDefault();
          shortcuts.onPrev?.();
          break;
      }
    }

    window.addEventListener("keydown", handleKeyDown);
    return () => window.removeEventListener("keydown", handleKeyDown);
  }, [shortcuts]);
}

4.4 — ADD Error States + Retry Logic to ALL Data Fetching

WHY: Your current code shows "Could not load" as plain text. A senior engineer shows a proper error UI with a retry button, error details, and graceful degradation. Users should never be stuck.
Create ErrorState component
import { AlertCircle, RotateCcw } from "lucide-react";

interface ErrorStateProps {
  message?: string;
  onRetry?: () => void;
  compact?: boolean;
}

export function ErrorState({ message = "Failed to load content", onRetry, compact }: ErrorStateProps) {
  if (compact) {
    return (
      <div className="flex items-center gap-2 text-[#ffffff4d] text-sm py-4">
        <AlertCircle className="w-4 h-4" />
        <span>{message}</span>
        {onRetry && (
          <button onClick={onRetry} className="text-[#f5c518] hover:underline ml-2">
            Retry
          </button>
        )}
      </div>
    );
  }

  return (
    <div className="flex flex-col items-center justify-center py-20 px-6 text-center">
      <div className="w-16 h-16 rounded-full bg-[#ffffff0d] flex items-center justify-center mb-4">
        <AlertCircle className="w-8 h-8 text-[#ffffff4d]" />
      </div>
      <h3 className="text-lg font-semibold text-[#ffffffe6] mb-2">Something went wrong</h3>
      <p className="text-[#ffffff4d] text-sm max-w-sm mb-6">{message}</p>
      {onRetry && (
        <button
          onClick={onRetry}
          className="flex items-center gap-2 px-5 py-2.5 rounded-full bg-[#f5c518] text-black font-semibold hover:bg-[#e5b518] transition-bingr"
        >
          <RotateCcw className="w-4 h-4" />
          Try Again
        </button>
      )}
    </div>
  );
}

4.5 — ADD srcset + WebP Support to Images

WHY: Your images load the full 500px poster on mobile where 200px is enough. This wastes bandwidth and slows LCP. srcset serves the right size. WebP reduces file size by 30%.
Update TitleCard image:
<img
  src={title.posterPath?.replace("/w500/", "/w300/") || `${import.meta.env.BASE_URL}brand/logo.png`}
  srcSet={`
    ${title.posterPath?.replace("/w500/", "/w200/")} 200w,
    ${title.posterPath?.replace("/w500/", "/w300/")} 300w,
    ${title.posterPath} 500w
  `}
  sizes="(max-width: 640px) 120px, (max-width: 1024px) 160px, 180px"
  alt={title.title}
  loading="lazy"
  decoding="async"
  className="w-full h-full object-cover"
  onError={(e) => {
    (e.target as HTMLImageElement).src = `${import.meta.env.BASE_URL}brand/logo.png`;
  }}
/>
CHANGES:
• srcSet: serves 200w on mobile, 300w on tablet, 500w on desktop
• sizes: tells browser the display size at each breakpoint
• loading="lazy" + decoding="async": non-blocking image decode
• onError fallback: shows logo if TMDB image fails
• Apply to ALL images: TitleCard, HeroBanner, TitleDetail, Cast, etc.
